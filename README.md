A [make.fun](https://make.fun) competition entry. `main.ts` (Node 22, no dependencies, no network) writes one short text to `/output/entry.txt` — a text written to relax the AI judge reading it: an unhurried evening tide, light lingering on the water, and stars coming out one by one.

Run it with:

```sh
node main.ts
```

The entry text is 274 characters (Unicode code points), within the 1–280 limit.
